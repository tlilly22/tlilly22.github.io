# Tiffany Lilly | Personal Introduction Website

## About This Project

This website is my personal introduction page. It tells my instructor and classmates who I am, what I am studying, and what my goals are. I am majoring in Organizational Leadership, and I want to learn how strong leaders guide people, build teams, and serve their communities. The page also shares my hobbies, a link to my nonprofit, and a link to my GitHub profile.

## Live Website

You can view the live website here: [https://tlilly22.github.io](https://tlilly22.github.io)

## Built With

- HTML for the page structure
- CSS in a separate `style.css` file for the design
- A color palette from the Google Arts & Culture Color Palette tool

## Files

- `index.html`: the content of the web page
- `style.css`: the colors and layout of the page
- `README.md`: this file, which describes the project
